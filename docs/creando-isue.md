# Guía: ¿Cómo crear una Issue en GitHub?

Una Issue (o incidencia/tarea) sirve para proponer mejoras, reportar fallos o planificar tareas dentro de un repositorio colaborativo. Sigue estos pasos para crear una nueva:

## Pasos para crear una Issue

1. **Entra al repositorio:** Dirígete a la página principal del proyecto en GitHub (por ejemplo, [monium/gitanddocs](https://github.com/monium/gitanddocs)).

2. **Accede a la pestaña de Issues:** En la barra de navegación superior (justo debajo del nombre del repositorio), haz clic en la pestaña **Issues** (aparece acompañada de un icono de círculo con un signo de exclamación y el número total de tareas abiertas).

3. **Inicia la creación:** Haz clic en el botón verde **New issue** situado en la esquina superior derecha.
   * *Nota:* Al apretar el botón, sale un menú desplegable para elegir la mejor categoría (como *Reporte de Bug*, *Solicitud de Funcionalidad*, *Pregunta / Duda*, *Tarea General*, etc.), la cual te da una plantilla predeterminada que se puede usar o rellenar desde cero seleccionando *Blank issue*.

4. **Rellena los campos principales:**
   * **Title (Título):** Escribe un título corto, claro y descriptivo que indique de qué trata la tarea (por ejemplo: *"Aprender a crear una Issue"*).
   * **Description (Descripción):** Explica detalladamente en qué consiste la tarea, qué problema resuelve o qué pasos se deben seguir para completarla. Puedes usar formato Markdown para ordenar el texto con listas o negritas.

5. **Asigna metadatos (Opcional):**
   * **Assignees:** En la barra lateral derecha, puedes asignarte la tarea a ti mismo haciendo clic en *Assign yourself* para que el resto del equipo sepa quién está trabajando en ello.
   * **Labels:** Añade etiquetas (como *documentation*, *bug* o *enhancement*) para categorizar el tipo de Issue.

6. **Finaliza la creación:** Haz clic en el botón verde **Submit new issue** ubicado en la parte inferior. ¡Listo! Tu Issue ya estará publicada y visible para todo el equipo.
